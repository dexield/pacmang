# pacmang

**pacmang** — это современный, быстрый и удобный графический менеджер пакетов для Arch Linux, написанный на GTK4 и Libadwaita. 

Приложение создано для тех, кто ценит эстетику GNOME и хочет управлять пакетами `pacman` и `yay` (AUR) без необходимости постоянно вводить команды в терминале.

---

## ✨ Возможности

* **Поиск пакетов**: Быстрый поиск в официальных репозиториях (`pacman`) и в AUR (`yay`).
* **Топ популярных пакетов**: При пустом поле поиска отображается список самых скачиваемых пакетов (на основе статистики `pkgstats`).
* **Умная сортировка**: Результаты поиска сортируются по релевантности (точное совпадение названия всегда будет первым).
* **Управление установленными пакетами**: Просмотр списка явно установленных пакетов и их удаление в один клик.
* **Обновление системы**: Запуск полного обновления системы (`pacman -Syu`) с графическим вводом пароля (`pkexec`).
* **Живой лог**: Отображение процесса установки/удаления в реальном времени прямо в окне приложения.
* **Нативный интерфейс**: Полная интеграция с рабочим столом GNOME благодаря Libadwaita.

## 📥 Установка

Пакет доступен в **AUR (Arch User Repository)**. 

Вы можете установить его с помощью любого AUR-хелпера (например, `yay` или `paru`):

```bash
yay -S pacmang
